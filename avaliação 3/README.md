# 2025.2-ProgComp
Repositório dos códigos desenvolvidos nas atividades avaliativas dos alunos de Programação de Computadores

> [!WARNING]
> 1. Os programas deverão ser desenvolvidos em linguagem PYTHON;<br/><br/>
> 2. Cada questão deverá ser respondida em arquivos em separado;<br/><br/>
> 3. As respostas deverão ser submetidas no repositório do assignment relativo a esta atividade;<br/><br/>
> 4. A primeira linha do arquivo deverá ser um comentário com sua matrícula completa seguida do seu nome completo no formato <strong>#matricula:nome completo</strong>;<br/><br/>
> 5. Está implícito que em todas as questões deverão ser tratadas as devidas exceções (específicas e genéricas);<br/><br/>
> 6. Atentem para o prazo de submissão. Ao término do prazo, o assignement será bloqueado automaticamente, não sendo possível novos commits;<br/><br/>
> 7. Não serão aceitos envios posteriores a data limite.
