## Questão 2: Mega Sena (30 pontos)

<hr/>

<p><strong>Contexto:</strong></p>

<p>Você recebeu um arquivo com os resultados de todos os concursos da Mega Sena para que sejam realizadas algumas implementações.</p> 

<hr/>

<p><strong>Objetivo:</strong></p>

<p>Nesse contexto, faça um programa em Python que efetue a leitura do arquivo <strong>Resultados_Mega_Sena.csv</strong> e monte uma lista. Cada posição dessa lista será uma sub-lista contendo os dados dos resultados dos sorteios das Mege Senas já realizadas.</p>

<p>Após essa implementação, desenvolva os códigos para realizar as seguintes operações:</p>

<ol>
  <li>O programa deve solicitar ao usuário um valor entre 6 e 20 e com base nesse valor gerar, aleatoriamente, a quantidade de dezenas informadas. As dezenas a serem escolhidas devem estar compreendidas entre 1 e 60 (sem repetições);<br/><br/></li>
  <li>Uma vez escolhidas as 10 dezenas, o programa deverá gerar 3 listas (as listas deverão ter os mesmos dados da lista original);<br/><br/></li>
  <ul>   
    <li>Uma lista contendo os dados dos sorteios contemplados com a Mega Sena;<br/><br/></li>
    <li>Uma lista contendo os dados dos sorteios contemplados com a Quina;<br/><br/></li>
    <li>Uma lista contendo os dados dos sorteios contemplados com a Quadra;<br/><br/></li>
  </ul>
  <li>Após gerar essas três listas, elas deverão ser salvas em arquivos em separado com os nomes: <strong>resultados_sena.csv</strong>, <strong>resultados_quina.csv</strong> e <strong>resultados_quadra.csv</strong>;<br/><br/></li>
  <li>Em seguida, o programa deverá exibir a quantidade de resultados da sena, da quina e da quadra obtidos;<br/><br/></li>
  <li>Por fim, com base na quantidade de dezenas informadas o programa deverá calcular a probabilidade de acerto para a sena, a quina e a quadra.</li>
</ol>
